## Design Specificity Verdict

**LLM assessment**: FAIL — category-interchangeable. Pilihan `Archivo` + `JetBrains Mono` adalah default kalibrasi (grotesk variabel + mono angka); justifikasi di DESIGN.md prosedural, bukan khas produk. Satu-satunya suara produk (`font-stretch: expanded` di merek + H1, mono arsip `BAB 01/08` dan tiket `WB/2026`) runtuh saat font perusahaan tanpa expanded axis dikirim. Tidak ada spesimen, x-height match, cek glif Indonesia, atau langkah ledger/stempel yang hanya milik dossier bengkel.

**Deterministic scan**: 1 temuan (`layout-transition` warning, `src/app.css:100` `transition: width` pada progress bar — di luar fokus tipografi). Checklist font: (a) `display=swap` + preconnect PASS; (b) fallback system-ui PASS; (c) tanpa hard-coded family PASS; (d) tanpa teks <12px PASS; (e) tanpa tracking <−0.04em PASS; (f) tanpa gradient/glass/halo PASS; (g) FAIL — `var(--mono)` dipakai untuk kalimat label (`merek-tag`, `navigator h2`, `kemajuan-teks`, `draf-info`, `unggah .meta`, `tabel th`, `lencana`, breadcrumb). Temuan (g) mengonfirmasi masalah konsistensi pada H4.

**Visual overlays**: tidak ada — tidak ada browser automation di sesi ini.

## Overall Impression

Kontrak body benar (16px/1.5/68ch) dan H1 disiplin, tetapi sistem tipografi berbicara kepada file system, bukan pengisi yang cemas: status dan bantuan dikecilkan, data dan prosa memakai pakaian yang sama, dan momen kirim — titik taruhan tertinggi — adalah kepala terdingin di seluruh alur. Peluang terbesar: bekukan swap font sampai spesimen ada, lalu naikkan semua teks pembawa status/aksi ke ≥14px dan kurung mono hanya untuk data.

## What's Working

1. Kontrak body benar: 16px/1.5, maks 68ch, sentence case, rata kiri, `::selection` + `:focus-visible` + underline offset. Jawaban Indonesia yang panjang tetap terbaca.
2. Disiplin H1: `clamp(30px,4vw,42px)/1.12/800/expanded/22ch`, lead 17px/60ch, tanpa badge di atas H1, CTA di viewport pertama.
3. Niat mono arsip (`BAB 01/08`, `WB/2026`, meta berkas) adalah suara dossier yang tepat — selama dikurung untuk data.

## Priority Issues

- **[P0] Swap font perusahaan tanpa spesimen meruntuhkan heading expanded + sistem mono.** `font-stretch: expanded` + sumbu `wdth` tanpa fallback; bobot 650/800, cakupan glif Indonesia, tabular figures, dan kawan mono belum diketahui. Fix: bekukan swap; minta nama + bobot + penanganan lebar + keputusan mono + lisensi/self-host + strategi `font-display`; catat di DESIGN.md sebelum sentuh `font-family`. Suggested: `/impeccable typeset`
- **[P1] Teks UI kritis 12px di navigator, progres, draf, dan batas unggah.** Batas berkas yang terlewat = submit gagal setelah 20 menit kerja. Fix: naikkan semua teks pembawa status/aksi ke ≥14px; 12px mono hanya untuk kode/sufiks ukuran. Suggested: `/impeccable layout`
- **[P1] Mono creep merusak sinyal data-vs-prosa.** 14 situs mono, separuhnya prosa (`merek-tag`, `navigator h2`, `kemajuan-teks`, `draf-info`, `unggah .meta`, `tabel th`, `lencana`). Fix: batasi `var(--mono)` untuk nomor/kode/ukuran; kembalikan kalimat ke Archivo 13–14px. Suggested: `/impeccable typeset`
- **[P2] Error vs help identik secara tipografi.** Bantuan 13px abu-abu di atas input vs error 14px bata di bawah — beda 1px + warna saja, tanpa isyarat bentuk. Fix: error 14px/700 + penanda teks + `aria-describedby` + blok ringkasan error ber-link ke kolom. Suggested: `/impeccable harden`
- **[P2] Tipografi inline-style di 5 titik melewati token.** Breadcrumb, legend, nomor ringkasan, margin tombol memakai `style="font-*"`. Swap font akan melewatkannya. Fix: ekstrak ke kelas token di `app.css`, larang inline font. Suggested: `/impeccable typeset`

## Persona Red Flags

**Jordan (first-timer)**: sub-navigator 12px tak terbaca sekilas — Bab 06/07 opsional dikira wajib; penanda `opsional` 13px abu-abu identik dengan label wajib; kartu radio `Gaya desain` tak memberi peringatan bahwa `Lainnya` memunculkan kolom; ringkasan Bab 05–06 `Terisi (periksa kembali…)` tak bisa diverifikasi tanpa klik-mundur.
**Sam (keyboard/SR)**: dua `h2` sejajar tanpa `h1` di `/brief` merusak hierarki SR; `aria-current="step"` pada `<button>` di luar konteks valid; `✓`/`○` tanpa alternatif teks; fokus gold 2px di atas tombol aktif navy minim visibilitas; `hidden` membuat 8 bab tetap di DOM.
**Casey (mobile 390px)**: navigator 9 tombol + progres mendorong `h2` bab 2–3 viewport ke bawah; placeholder ghost 16px bersaing dengan bantuan 13px di bawah cahaya; `Hapus draf` destruktif berdampingan dengan `Kembali` di baris sempit.

## Minor Observations

- `th` tabel admin mono 12px berbisik sementara sel 14px berteriak — balikkan.
- Miniatur dossier landing memakai suara berlawanan dengan wizard (sans+mono terbalik).
- `font-weight: 650` non-standar jadi 700 di Windows tanpa variable synthesis — verifikasi pada font perusahaan.
- `caret-color` diklaim DESIGN.md tetapi absen di `app.css` — spec drift.

## Questions to Consider

- Jika font standar perusahaan ternyata Calibri/Arial tanpa expanded axis dan tanpa kawan mono, apa yang tersisa dari tesis "dossier bengkel"?
- Mengapa data mesin (`maks 5MB`) bersuara arsip sementara kepastian manusia (`Draf tersimpan otomatis`) diketik paling kecil?
- Jika JetBrains Mono dihapus besok, angka mana yang benar-benar dirindukan pengguna — dan mengapa itu belum lebih besar, tabular, dan sans-proof?
